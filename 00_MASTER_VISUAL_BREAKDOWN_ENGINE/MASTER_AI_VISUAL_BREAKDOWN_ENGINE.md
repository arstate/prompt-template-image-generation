## 🚫 ATURAN ANTI-GRAPHIC-SLOP (PELAJARAN DARI KESALAHAN HASIL GENERATE):
1. **DILARANG MENGGUNAKAN KATA 'CUTOUT' / 'POP-OUT' SECARA CEROBOH:**
   - Kata *cutout* memicu generator AI memunculkan **garis tepi putih tebal (white sticker outline / die-cut border)** seperti stiker tempel murahan!
   - Ganti dengan: `isolated photographic subject seamlessly placed over background with zero white outline, natural seamless edges`.
2. **DILARANG MENGGUNAKAN KATA 'Y2K CYBER' / 'TEASER POSTER' TANPA PENGAWASAN:**
   - Kata tersebut memicu AI memunculkan **sampah visual retro**: jendela browser PC (`_ x`), kotak window retro, barcode, halftone dots / screentones, stiker bintang (*starburst*), dan teks acak sampah (*COMING SOON, NEW SINGLE, huruf Korea ngawur*).
   - Ganti dengan: `clean high-fashion minimalist Swiss-style graphic editorial poster`, `flat solid monochromatic magenta color blocks`, `zero stickers, zero UI elements`.
3. **NEGATIVE PROMPT KHUSUS POSTER GRAFIS (WAJIB DIPASANG):**
   - Wajib selalu menyertakan parameter anti-slop grafis berikut:
     `white sticker outline, white border around person, die-cut outline, sticker effect, computer window UI, browser buttons, halftone dots, screentone pattern, starburst stickers, decorative badges, barcodes, coming soon text, new single text, korean text, hangul, placeholder text, gibberish typography, cluttered graphics, messy overlay`

## 🚫 ATURAN MUTLAK GENERASI PROMPT (NON-NEGOTIABLE):
1. **Dilarang Keras Menggunakan Kurung Siku (`[]`):** Seluruh prompt wajib berupa teks deskriptif mengalir bersih tanpa placeholder kurung siku.
2. **Dilarang Menyertakan Parameter Aspek Rasio (`--ar`):** Dikosongkan di dalam prompt agar pengguna bebas mengetik rasio kanvas sendiri di paling belakang (misal `--ar 3:4` atau `--ar 9:16`).
3. **Pemisahan Mandiri & Ekstrem (5 Layer Terpisah):**
   - Layer A: Base Layout & Color Blocking Plate (Latar & Blok Grafis Polos tanpa orang).
   - Layer B: Model Head & Facial Portrait Plate (Wajah, riasan, aksesori kepala, ekspresi).
   - Layer C: Outfit, Styling & Footwear Plate (Busana lengkap, material tekstil, sepatu).
   - Layer D: Pose, Anatomy & Camera Framing Snippet (Pose gestur, posisi tangan, sudut kamera).
   - Layer E: Master Composite Prompt (Poster grafis editorial bersih 100% jadi).
4. **Standar Bebas AI Slop:**
   - Gunakan terminologi kamera optik nyata (Sony A7R V, Hasselblad H6D-100c), bukaan f/5.6 - f/8, pencahayaan high-key studio flash terarah, dan tekstur kulit asli dengan pori-pori mikro (*sub-surface scattering*).
5. **Parameter Bawaan:** Setiap prompt wajib ditutup dengan parameter `--style raw --c 1 --s 65` dan seed rekomendasi.
